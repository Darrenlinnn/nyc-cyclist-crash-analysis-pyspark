# Data

Not included (222 MB). Download [Motor Vehicle Collisions - Crashes](https://data.cityofnewyork.us/d/h9gi-nx95) from NYC Open Data and save it as `data/bike_crashes.csv` with these columns:

`collision_id, crash_datetime, borough, latitude, longitude, on_street_name, cross_street_name, cyclists_injured, cyclists_killed`

(The raw export names them `crash_date` + `crash_time`, `number_of_cyclist_injured`, `number_of_cyclist_killed`. Rename or combine them first.)
